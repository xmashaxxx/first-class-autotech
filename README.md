# C&A Auto Repair Website Template

Full website build for an independent auto repair shop in South Florida. The client ultimately decided against maintaining a web presence, so the site was never deployed for them; preserved here as a reusable template for future automotive service clients.

**Live preview:** [xmashaxxx.github.io/c-and-c-parts-repair](https://xmashaxxx.github.io/c-and-c-parts-repair/)

## Context

Built as part of Xsellera's client pipeline. After completing the full design and development, the client decided they preferred operating without a website. Rather than discard the work, the site is maintained as an open template, any auto repair shop wanting a professional web presence can use this as a starting point.

This happens in real client work. A completed project that doesn't ship is still a completed project, demonstrating the ability to take a brief from zero to a finished, deployable product.

## What's Included

- Home page with hero, services overview, and trust signals
- Services detail page
- Contact and location section
- Mobile-responsive layout

## Tech Stack

`HTML` `CSS` `JavaScript` `GitHub Pages`

## Reuse

This template is designed for adaptation. Any automotive service business can fork this repo and customize:
- Business name, logo, and brand colors
- Services list and pricing
- Location and contact details
- Photos and media
